IL2CPP Dump RVA Finder

Tìm RVA trong dump.cs và cập nhật địa chỉ vào file mã nguồn ngay trên trang này.

01. Nạp file dump

Trên điện thoại: nhấn “Chọn tệp / Browse”, mở mục Tệp hoặc Downloads rồi chọn dump.cs. Bộ chọn tệp cho phép chọn mọi loại file để tránh điện thoại lọc mất file .cs.

Chưa chọn file.

02. File mã nguồn cần cập nhật

Chọn file .h, .cpp, .mm hoặc .txt có chứa các hàm/địa chỉ cũ. Sau khi nạp dump.cs và file mã nguồn, bấm “Cập Nhật RVA” để tạo file đã cập nhật và tải về.

Chưa chọn file mã nguồn.

03. Danh sách hàm cần cập nhật RVA

Mỗi dòng nhập một chữ ký hoặc tên hàm. Nếu trùng kết quả, thêm Class theo dạng ClassName::MethodName (ví dụ HeroSelectNormalWindow::InitTeamHeroList). Cách nhập chữ ký đầy đủ vẫn được hỗ trợ.

Chưa cập nhật RVA.
#HàmClassRVA mớiTrạng thái
Nạp dump.cs rồi bấm Cập nhật RVA để hiển thị kết quả.

04. Cấu hình tìm kiếm

Để trống bộ lọc nếu chỉ muốn tìm theo tên hàm. Tham số được đối chiếu theo tên kiểu và số lượng.

05. Kết quả

0 Phương thức khớp
0 Có RVA
0 Chưa có RVA

Hãy nạp dump và nhấn Tìm RVA.

Công cụ xử lý cục bộ trong trình duyệt. File gốc không bị sửa; chức năng Cập Nhật RVA tạo và tải xuống một bản sao đã cập nhật.
